Mechatronics Prototyping

Mobile Gantry Crane

A rapid prototyping project that combined custom mechanical design, 3D-printed components, DC motor actuation, breadboard electronics, and Arduino-based control in a functional mobile crane.

Fusion 360 Arduino 3D Printing DC Motors Rapid Prototyping

Project Overview

From concept to a working physical system

The project was completed on a compressed timeline, so the team prioritized mechanical feasibility, fabrication, electrical integration, and reliable basic motion.

The objective was to create a stable mobile gantry crane capable of moving across the floor, translating a suspended carriage, and lifting an object.

The final prototype integrated an aluminum-extrusion frame, custom carriage and pulley assemblies, a spring-loaded mobile base, multiple DC motors, breadboard electronics, and simple Arduino-based drive control.

Mechanical Design

Custom CAD components were designed around the available aluminum extrusion, shafts, motors, and fabrication tools.

System Integration

The structure, carriage, transmission, electronics, and mobile base were assembled into one working prototype.

Functional Result

The completed crane demonstrated base movement, carriage travel, vertical lifting, and object pickup.

Design Development

CAD-guided design and rapid fabrication

Early CAD work established the crane geometry and helped determine dimensions for the remaining mechanical subsystems.

Carriage System

Using the frame as part of the motion system

The built-in slots of the aluminum extrusion were used as rails for a custom carriage carrying the lifting subsystem.

The carriage was designed around the available 20 mm aluminum extrusion, reducing the need for a separate linear rail system. Its plate structure supported the motors, shafts, winches, and vertical load.

Shaft collars and custom 3D-printed spacers provided axial support and allowed the assembly to be adjusted around the available hardware.

Transmission Design

Custom winches, pulleys, and line routing

The lifting and horizontal travel systems used custom components designed around 5 mm shafts and the available motors.

A cone-shaped winch profile helped guide the lifting line, while a separate line pulled the carriage along the frame.

The driven horizontal pulley used a textured surface to improve grip and reduce line slippage. A custom housing supported the pulley set and accommodated string tension.

Mobile Base

Maintaining drive-wheel traction

A spring-loaded parallel four-bar suspension kept the powered wheels in contact with the floor while preserving support at the crane's corners.

Electronics & Control

Simple controls for physical validation

The controls were intentionally kept straightforward so the team could validate the complete mechanical system within the project schedule.

An Arduino and L298N motor driver controlled the two base motors using differential drive. Separate bidirectional controls reversed polarity for the carriage and lifting motors.

The implementation supported basic motion testing and object pickup, but did not include closed-loop position control, homing, or autonomous task sequencing.

Final Result

A functional integrated prototype

The completed crane demonstrated that the structure, transmission components, electronics, and actuators could operate together as one mechatronic system.

Mobile Movement

Differential drive enabled forward movement, reverse movement, and turning.

Carriage Travel

The custom carriage moved along the aluminum-extrusion frame.

Object Lifting

Reflection

Planned next-stage improvements

Once the physical architecture was validated, the next development stage would focus on feedback, repeatability, and higher-level automation.

Homing

Add limit switches and reference positions for each motion axis.

Closed-Loop Control

Add encoder feedback and PID control for repeatable positioning.

Automated Sequencing

Coordinate base, carriage, and lifting motions into repeatable pickup routines.
